## 📝 Project Overview

This repository aggregates six specialized Power BI dashboards, each designed to extract insights from unique datasets and present them through interactive charts, filters, and KPI visuals. Ideal for stakeholders seeking to explore trends, compare key metrics, and make informed decisions.

---

## 📊 Analytics Dashboards

| Dashboard                   | Description                                                     |
|-----------------------------|-----------------------------------------------------------------|
| Budget vs Sales Analysis    | Compare budget allocations against actual sales performance.    |
| Heart Disease Analysis      | Identify clinical attributes and risk factors for heart disease.|
| Pokémon Analysis            | Analyze Pokémon stats, types, and evolution patterns.           |
| Retail Sales Analysis       | Explore transaction data, customer segments, and revenue trends.|
| School Data Analysis        | Assess academic performance and demographic distributions.      |
| Titanic Survival Analysis   | Examine passenger demographics and survival rates.              |

## ⚙️ Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/powerbi-analytics.git
   cd powerbi-analytics


2. **Open dashboards**

   * Launch Power BI Desktop and open the desired `.pbix` file from the `reports/` folder.
3. **Install visuals**

   * If prompted, install any missing custom visuals via Microsoft AppSource.

---

## ▶️ Usage Guide

* **Filters**: Use the filters pane to slice data by dimensions like Region, Category, and Year.
* **Drill-down**: Click on chart elements to drill into detailed views.
* **Exports**:

  * **PDF**: File → Export → PDF
  * **PowerPoint**: File → Export → PowerPoint
